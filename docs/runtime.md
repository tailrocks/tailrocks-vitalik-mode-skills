# Runtime requirements

Install the [complete package](installation.md). The native registrars only
register skill files. Skill procedures control when to call tools or execute a
script. Installation grants no authority for a skill action.

Run the mode through the host's skill interface. An explicit user command
activates or disables it. The active goal and its record live in the user's
session or work context. Keep unfinished recovery and deferred issues there.

Use an authorized host planner route when available. Keep execution with the
primary agent. See [usage](usage.md) for activation, continuation, and fallback.
The skill uses instructions, references, and assets. The Python validator
serves maintainers.
